# marcosjunca.com

The source of [marcosjunca.com](https://marcosjunca.com): one static page, served by GitHub Pages from
this repository. No build step, no scripts, no tracking.

- `index.html`: the page, styles included (light and dark follow the system setting)
- `og.png`: the card shown when the link is shared
- `CNAME`: the custom domain for GitHub Pages
